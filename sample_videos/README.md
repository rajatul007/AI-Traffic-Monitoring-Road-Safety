# Sample Traffic Videos

This folder contains guidelines and download links for sample traffic videos to test the Upload Video mode.

## Recommended Test Datasets
1. **Urban Highway Day**: High-angle highway traffic video with cars, buses, and trucks.
2. **Intersection Traffic**: Busy intersection with traffic signal and pedestrian crossing.
3. **Motorcycle Lane**: Urban road footage containing motorcycles and scooters for helmet/rider testing.

## Direct Sources for Open-Access Traffic Clips
- **Pexels Free Traffic Videos**: Search "Highway traffic aerial" or "City intersection camera" (MP4, 720p/1080p).
- **DAVIS Traffic Dataset / UA-DETRAC**: Standard benchmark datasets for vehicle detection & tracking.

## Built-in Demo Test Clips
The frontend includes a built-in "Load High-Resolution Sample Traffic Simulation" option so you can test complete end-to-end detection, vehicle counting, and violation capture immediately even if you don't have an MP4 file on hand!
